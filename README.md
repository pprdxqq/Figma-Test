# Northstar® — Digital Studio Demo

A responsive single-page studio website created as a GitHub + Figma workflow example.

## Preview locally
Open `index.html` in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## What's included
- Responsive desktop and mobile layouts
- Project showcase cards
- Services section and contact CTA
- Scroll reveal motion with reduced-motion support
- Semantic HTML and focus-visible states
- No build step or external dependencies

## Figma design
Editable desktop and mobile artboards, plus reusable project-card and contact-button components:

## Notes
This is a fictional studio demo, not a real client site. The contact email uses a reserved example domain and should be replaced before production.
